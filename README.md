Steps to setup and run the software
Install git
Windows - https://git-scm.com/downloads/win

Install Code editor
VS code for Windows - https://code.visualstudio.com/download

Install Node.js & npm
For Windows - https://nodejs.org/en/download

Open terminal in the root folder and run
npm i
to install all the packages

Run : npm start in the root folder to start the backend server
If it doesn't work, install nodemon globally and then run: nodemon server

To start the client (expo app)

cd ./client
npm start

Install Postman
Windows - https://www.postman.com/downloads/
